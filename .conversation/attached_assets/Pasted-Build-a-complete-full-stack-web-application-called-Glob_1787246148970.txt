1. CORE CONCEPT
==================================================

GlobalTalk allows users to meet people from different countries through live video conversations.

A user:

1. Creates an account.
2. Selects their country.
3. Selects languages they speak.
4. Selects languages they want to practice.
5. Selects interests.
6. Selects preferred countries.
7. Clicks "START TALKING".
8. Enters the matchmaking queue.
9. Gets matched with another eligible user.
10. Joins a private video conversation.
11. Can chat by text.
12. Can skip to another person.
13. Can report or block the other user.
14. Can end the conversation.

The experience should feel fast, simple and exciting.

10. MATCHMAKING
==================================================

Implement real server-side matchmaking.

When the user clicks START TALKING:

1. Check authentication.
2. Check account status.
3. Check age eligibility.
4. Check whether the user is already in a match.
5. Check blocked users.
6. Add the user to matchmaking queue.
7. Search for compatible users.
8. Create a match.
9. Create a private video room.
10. Generate secure video credentials.
11. Send both users into the video room.

Matching should consider:

- Country preferences
- Language preferences
- Shared interests
- Matching mode
- User availability

Matching priority:

1. Preferred country + language + shared interests
2. Language + shared interests
3. Shared interests
4. Compatible language
5. Random eligible user

Do not match users who have blocked each other.

Do not immediately rematch users who just spoke unless necessary.
